Chào bạn 👋 Mình là VeltoZ. Bạn đang chọn FC Mobile — hỏi mình về đội hình, chiến thuật hoặc nâng cấp nhé.

Kiến trúc bảo mật của bản triển khai này

Trang bạn đang xem chỉ gọi tới /api/chat trên chính domain này. API key thật nằm trong file .env trên server, được đọc bởi server.js và không bao giờ được gửi xuống trình duyệt — kiểm tra bằng "View Page Source" sẽ không thấy key ở đâu cả.

  1. Trước khi chạy: thu hồi (revoke) 3 key bạn từng dán trong chat trước đó, vì chúng đã lộ trong lịch sử hội thoại.
  2. Tạo key Anthropic mới, dán vào file .env (sao chép từ .env.example) — không dán vào bất kỳ file trong public/.
  3. Chạy npm install rồi npm start để khởi động backend tại localhost:3000.
  4. Khi deploy thật, đặt biến môi trường ANTHROPIC_API_KEY trên nền tảng hosting (Render, Railway, Fly.io...), không commit file .env lên Git.
